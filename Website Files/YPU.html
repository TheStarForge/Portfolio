You Pass Universe

Platform: Windows | Engine: Unreal Engine 5 | Role: Lead Front-End Engineer

You Pass Universe is a social platform that gives users the ability to host and customize their own virtual world, and communicate with others within a secured network where privacy takes top priority.

As a front-end engineer, I have been responsible for the following:

  • Utilized Unreal Blueprints and C++ to add functionality to actors
  • Created and modified 3D blender assets to be imported into unreal
  • Worked with backend developer to implement peer-to-peer networking
  • System pipeline integration via Perforce, Nextcloud, Fossil, and OpenProject
